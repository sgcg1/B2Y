## 设计与验证

- 对照：default H128/PARALLEL_SCAN=True，candidate H256/PARALLEL_SCAN=False。其余算法、工作量、输入输出布局相同。两者使用同一TIR入口、相同手工预分配输出，排除自动输出分配方式差异；默认生成CPP必须与公共Kernel完全一致。
- 每个独立进程先确认公共manifest Decode通过，再对两档分别执行原12项测试体×3次，复用公共reference/validator和位模式/确定性保护；同步诊断则拒绝执行。
- 性能输入三类：固定随机、全同分、同一粗桶内相邻FP32值；均全窗口，FP32[1,1,16384,1]、K2048，不缩7/8。保存每类输入SHA，要求同进程两方法及三个进程间一致。
- 每类/方法窗口外预热3次，每进程5对采样，顺序按pair及进程轮次交替。3个独立Python进程，合计每类每方法15样本，正式比较样本共90个。
- 每次前1GiB int32驱逐并同步，均在计时窗口外；记录单次完整选择kernel的原始FFTS/STARS设备区间。每个样本要求1个逻辑任务，采样后用公共validator检查结果与输入保护；参考计算、验证和预热均不计时。
- 每个进程额外有1个驱逐kernel名称解析自检窗口，3个自检不算入90样本。解析失败明确终止，无Event/墙钟回退。保留全部样本与trace，不挑最好值。

这轮可能比前几轮更久：3个进程均会编译并保留30个计时窗口，自动按序执行，不要重复启动。任一进程失败即停，不继续凑齐样本。

## 测量边界与判读

这是同环境、同一完整TopK选择kernel的设备时间（预分配输入输出），不是host调度总延迟，不是重新测TopKV2。公共默认Op此前已验证；候选本轮以独立TIR编译，不自动成为公共默认。三个进程返回后汇总全部15样本，比较均值、标准差、各进程差异和逐对差值，分别报告三类数据；单次AutoTuner14.31%不预设为本轮结论。

默认是否更新，要等审查实际收益与退化后再决定；如更新仍需公共Op完整回归。当前不进入其他新算法/缓存开关，不声称稳定优于ops-math，不把本轮与历史Event或截图直接拼倍率。
